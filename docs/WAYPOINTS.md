# 05 · 编辑和执行航点任务

[上一章：RViz 面板](RVIZ_PANEL.md) · [文档导航](README.md)

本章完成一次短距离多点飞行，练习单步、停止保持和文件保存。前提是通过当前核心起飞并进入保持，状态有效、在空中且已解锁。仅让飞控进入 OFFBOARD，不能代替由当前核心建立控制。

## 1. 坐标与示例适用条件

航点 X/Y/Z 是 `map` 下的**绝对 ENU 坐标**：X 向东、Y 向北、Z 向上，单位为米。Yaw 在面板和 YAML 中使用度，0° 朝向 +X，正向从 +X 转向 +Y；Action 接口使用弧度。

[方形航线示例](examples/waypoints_square.yaml)包含五点，在 Z=1 m 处从 `(0,0)` 出发沿 1 m 边长方形回到起点，所有 yaw 为 0°。文件中不包含起飞或降落指令。

此例用于默认 SITL 原点附近、空旷环境下的练习。加载前查看当前位置；若实际起飞点不在原点附近，优先用“添加当前位置”创建航点，或将示例全部平移到当前位置附近。地图原点不保证等于起飞点，Z=1 也不表示离任意地面 1 m。

核心要求当前位置到首点、相邻点以及循环闭合段距离不超过 10 m，最多 500 点。面板不规划避障路径；距离合法不代表中间没有障碍物。

## 2. 加载示例，核对任务选项

在面板点击“加载 YAML”，选择：

```text
<FC-Sim 仓库>/docs/examples/waypoints_square.yaml
```

成功提示为“已加载草稿，不影响运行中的任务”。表格应有五行，任务选项如下：

| 选项 | 示例值 | 含义 |
|---|---|---|
| XYZ 阈值 | 0.15 m | 三维距离到目标的容差，不是每轴独立容差 |
| 检查偏航到达 | 开启 | yaw 也必须满足到点要求 |
| Yaw 阈值 | 10° | 朝向误差容差 |
| 到点停留 | 0.5 s | 持续满足到点条件的时间 |
| 单点超时 | 60 s | 包含飞行与到点停留；超时则任务失败 |
| 循环执行 | 关闭 | 完成五点后保持最后目标 |

取消“检查偏航到达”只跳过 yaw 到点判断，仍发送 yaw 目标。到点后若离开容差范围，停留计时重新开始。

加载只校验文件结构与数值，不代表当前飞行条件满足任务准入；距离、地面状态和控制权仍在提交时由核心检查。

## 3. 执行全部

1. 确认当前核心处于保持，核对五个航点及橙色当前目标。
2. 点击“执行全部”，等待请求接受。
3. 观察航点进度和目标变化。位置达到阈值且停留完成后才算完成一个点。
4. 等待动作结果 `0`，状态回到保持。此时飞机仍在空中，任务不会自动降落。
5. 完成本章其他练习或直接点击“降落”收尾。

这五行包括首点与回到首点，因此正常完成计数为 5。接口的 `waypoint_index` 从 0 开始；面板显示的航点序号从 1 开始。循环时 `completed_count` 跨圈累计。

发送的是提交时的航点快照。执行期间修改表格、选项或加载另一个文件，都不会修改当前任务。

## 4. 从当前位置开始编辑与单步执行

若不适合使用绝对原点示例：

1. 起飞保持后删除不需要的草稿行，点击“添加当前位置”，得到当前 XYZ/yaw。
2. 再次添加当前位置，将新行 X 增加 1 m，Z 和 yaw 保持不变。
3. 选中第一行，点击“单步执行选中点”。它只提交一个点，即使勾选循环也不会循环。
4. 成功后自动选中下一行，再次点击单步执行，观察约 1 m 的位移。

若任务失败，或执行期间编辑过表格，面板不会按原快照自动跳到下一行。单步不是“暂停执行全部”，每次都是新的单点任务。

“添加”和“插入”使用 X=0、Y=0、默认 Z、Yaw=0；“添加当前位置”才会复制实时位姿。默认最大航点数为 50，可调至 500；调小容量不会截断已有草稿。

## 5. 循环与停止保持

完成一次非循环任务后再练习循环：勾选“循环执行”，点击“执行全部”，观察累计完成数和圈数增长。循环不会自行成功结束。

任务执行中点击“停止 / 保持”，应收到停止请求已接受，随后 `mission_active: false`、`holding: true`，核心改为保持停止时的位置。确认后取消勾选循环，避免下一次误提交循环任务。

停止服务结束航点时，现有实现会让任务 Action 以 `ABORTED` 和结果码 `8`（PREEMPTED）结束；这与正常完成的结果 `0` 不同。结合 stop 服务成功、结果说明和保持状态判断停止是否完成。Action cancel 是另一条路径，不能仅凭终态名称将两者混为一谈。

点击“降落”也可抢占任务并收尾。关闭 RViz 不会停止循环任务。

## 6. 保存和重新加载

点击“保存 YAML”，另存为自己的文件。编辑一处草稿后重新加载保存文件，确认航点和选项恢复；加载操作不发送任务。YAML 结构可直接参考[示例文件](examples/waypoints_square.yaml)。

- `schema_version` 必须为 1，`frame_id` 必须为 `map`。
- `vehicles` 中必须有当前核心名称，例如 `/flight_core`；文件不会自动切换控制对象。
- 文件上限为 4 MiB，最多 100 个车辆条目，每个条目最多 500 点。
- 加载失败会保留原草稿。保存会保留已加载文档中其他车辆条目，但不代表当前面板同时控制多机。
- 表格和 YAML 使用 `yaw_deg`；不能把弧度值直接填入角度字段。

## 常见问题与验收

| 现象 | 检查与恢复 |
|---|---|
| “请先添加航点”或“请选中航点” | 检查表格及单步选中行 |
| 文件没有当前核心命名空间 | 核对 YAML 的 namespace 和面板连接对象 |
| 任务提示需要当前核心保持 | 先使用当前核心完成起飞并确认 holding；不要旁路手工切模式 |
| 航点或航段超过 10 m | 核对绝对坐标、当前到首点距离和循环闭合段 |
| 到点后仍未切换 | 检查 XYZ、yaw 和持续停留条件；仅看位置接近不足以判断 |
| 单点超时或任务失败 | 读取结果与状态说明，确认后续保持/降落状态后再提交；某些失败会进入降落清理 |

验收包括五点成功、单步成功后选行、循环停止后保持、文件保存加载往返以及最后降落。各项实际覆盖情况见[验证记录](VALIDATION.md)。
