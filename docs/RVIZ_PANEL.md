# 04 · 使用 RViz 飞行面板

[上一章：首次飞行](QUICKSTART.md) · [文档导航](README.md) · [下一章：航点任务](WAYPOINTS.md)

本章通过面板完成连接检查、起飞和降落。先按快速开始启动 PX4、MAVROS 和核心，保持它们运行。面板通过 Action 和服务控制核心，持续飞行控制仍由核心承担。

## 1. 打开面板

新开终端，执行[公共环境前缀](BUILD.md#5-后续每个-ros-终端的公共前缀)，然后运行：

```bash
ros2 launch flight_rviz_plugins panel.launch.py
```

应出现 RViz 的“飞行控制”面板、网格和“航点与当前目标”显示项。此命令只启动 RViz。已有 RViz 窗口也可通过 Panels → Add New Panel → `flight_rviz_plugins/FlightPanel` 添加面板。

控制核心填写 `/flight_core`，点击“连接”。使用默认配套配置时 Fixed Frame 为 `map`，MarkerArray 话题为 `/flight_core/panel_markers`。同一核心建议只开一个面板实例。

## 2. 起飞前读懂状态

| 界面区域 | 要检查什么 |
|---|---|
| 遥测更新提示 | 应为“实时更新”，不能停留在“等待遥测”或“遥测已过期” |
| 四个状态徽标 | 已连接、状态遥测有效、位置姿态有效；首次起飞前已上锁 |
| 飞控模式、操作、执行阶段 | 结合结果判断当前动作，英文原值可通过鼠标悬停查看 |
| 着陆状态 | 首次起飞前为“在地面” |
| X/Y/Z/Yaw | 位置为米，Yaw 为度；`—` 表示当前值不可用 |
| 操作反馈 | 区分“正在提交”“请求已接受”和最终“动作结果” |

状态超过约 1 s 未更新或时间戳过期时，控制按钮禁用。按钮可点仍不等于核心必然接受请求，服务端会再次验证条件。

## 3. 起飞、保持和降落

1. 将“起飞相对高度”从面板默认的 **2 m** 改为 **1 m**，与快速开始一致。
2. 确认状态有效、在地面且已上锁，点击“起飞”。不需要先单独点击“解锁”。
3. 等待操作反馈显示动作结果 `0`，并观察状态进入位置保持、在空中且已解锁。仅看到“请求已接受”时继续等待。
4. 若要练习航点，此时进入[下一章](WAYPOINTS.md)，保持核心与 MAVROS 运行。
5. 完成练习后点击“降落”，等待动作结果 `0`、在地面且已上锁，再关闭窗口和其他进程。

“解锁”“上锁”是独立地面操作，本节的起飞流程会自行处理所需解锁步骤。不要用上锁按钮代替空中的降落。

关闭面板不会取消已提交的任务。停止命令行客户端或关闭 RViz 也不会让核心自动降落。

## 4. 停止与降落的区别

“停止 / 保持”请求核心 stop 服务：航点任务中尝试保持当前位置，起飞过程中则请求降落清理。它没有继续执行剩余任务的“恢复”语义；再次执行会提交新任务。

“降落”提交降落 Action，可以抢占任务。停止请求返回已接受后仍应观察实际状态；需要落地时使用降落并等待确认。

## 5. RViz 点选与目标显示

- 使用工具栏 **2D Goal Pose**，在网格上按下并拖动：位置确定 XY，拖动方向确定 yaw。
- “新增点默认 Z”补全高度；点选不会读取地形高度，也不会立刻发送飞行任务。
- 只接受 `map` 帧和有效四元数，面板不会自动转换其他坐标系。
- 蓝色箭头和编号表示表格草稿；橙色箭头表示核心报告的当前目标。编辑蓝色草稿不会改变已提交目标。
- 状态过期后当前目标隐藏，草稿仍可编辑。默认配置没有 Gazebo 模型或完整环境地图，RViz 网格不等于仿真场景中的障碍物地图。

## 6. 保存与重新连接

RViz 配置保存核心名称；航点需要单独“保存 YAML”。直接保存 RViz 配置不会保存航点内容。

更换核心名称时，面板分别保留本次运行期间的草稿；有活动请求且状态新鲜时不能切换。失联后重新连接不会取消旧核心中的任务。使用其他核心名称时，还需同步修改 MarkerArray 的 Topic；本教程仍只操作 `/flight_core`。

## 常见问题与验收

| 现象 | 检查方法 |
|---|---|
| 找不到 FlightPanel 插件 | 确认已编译 `flight_rviz_plugins` 并加载本仓库 install；重开 RViz |
| 等待遥测、按钮灰色 | 检查核心进程、核心名称、ROS 域与环境前缀 |
| 位置显示 `—` | 检查状态新鲜度和 `pose_valid`，不能用旧数值继续判断 |
| 看不到草稿箭头 | 检查表格是否有点、Fixed Frame 是否为 map、MarkerArray 话题是否正确 |
| 请求被拒绝或结果非零 | 阅读结果文本和状态说明，先排除忙碌、遥测和控制权条件 |

本章验收：面板连接正确、状态持续更新，完成 1 m 起飞—保持—降落，并观察到最终结果。当前自动化与实际 GUI 验证范围见[验证记录](VALIDATION.md)，不能将离屏测试当作人工按钮操作验收。
